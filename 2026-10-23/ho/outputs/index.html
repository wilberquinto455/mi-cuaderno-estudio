DATOS

Bases de datos

Temas para documentar

Modelo relacional, tablas y claves; normalización; consultas SQL; relaciones y JOIN; índices, transacciones y respaldos.

Consultas de referencia

SELECT nombre, correo
FROM estudiantes
WHERE activo = TRUE
ORDER BY nombre;

-- Relaciona filas de dos tablas
SELECT e.nombre, c.nombre AS curso
FROM estudiantes e
JOIN cursos c ON c.id = e.curso_id;

Ideas para practicar

  1. Diseña una base de datos para una biblioteca.
  2. Define claves primarias y relaciones.
  3. Inserta datos de prueba y crea consultas para responder preguntas.
  4. Guarda el diagrama y las consultas como parte del lab.

PARA ESTUDIAR MEJOR

Recomendaciones

Para CCNA

  • Alterna teoría con laboratorios de configuración y troubleshooting.
  • Practica subnetting con frecuencia y explica en voz alta cómo llegas al resultado.
  • Después de cada tema, resume comandos, conceptos y errores comunes con tus palabras.

Para lógica

  • Escribe primero los pasos en lenguaje natural o pseudocódigo.
  • Prueba casos normales, límites y entradas inesperadas.
  • Cuando funcione, intenta resolver el mismo problema de otra manera.
